# Withinly Wellness AI

Smarter Nutrition, Fitness, and Wellness for South Indian Women

## About
Withinly is an AI-powered wellness platform designed for South Indian women aged 18–30. It provides personalized nutrition plans, fitness recommendations, wellness tracking, and AI-driven insights.

## Features
- Personalized diet plans
- Workout recommendations
- Wellness tracking
- AI-powered guidance
- Progress monitoring
- South Indian food-focused nutrition

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vite
